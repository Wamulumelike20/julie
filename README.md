# For Juliet

A single-page proposal site. Plain HTML, CSS and JavaScript, no build step.

    index.html
    css/style.css
    js/main.js
    assets/audio/   (the three songs)

## Run it locally
    python3 -m http.server 8000
then open http://localhost:8000

## Put it on GitHub Pages
1. Create a repository and upload everything in this folder, keeping the folders as they are.
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Open the link GitHub gives you.

## Settings
In js/main.js, set WHATSAPP (country code, no +) to show a "Message me" button on the Yes screen.
